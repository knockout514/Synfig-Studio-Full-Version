## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Vector-Based Animation** — Create smooth 2D animations using independent spatial resolution to avoid pixelation.
- **High-Quality Output** — Generate stunning animations without compromising quality, thanks to the software's advanced interpolation techniques.
- **HDRI Processing** — Enhance illumination and color composition for more visually appealing animations.
- **Drawing Tool Support** — Utilize drawing pads for precise and flexible drawing capabilities.
- **User-Friendly Interface** — Navigate easily with a familiar workflow similar to other commercial animation tools.

### Advanced Features:
- **Template Library** — Access a variety of pre-designed templates to jumpstart your animation projects.
- **Layer Management** — Organize your work using layers for a more streamlined animation process.
- **Customizable Tools** — Tailor your workspace with floating windows for layers, history, and tools.
